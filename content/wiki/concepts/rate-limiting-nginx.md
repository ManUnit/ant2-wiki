# Rate Limiting in NGINX

Per-host rate limiting implemented in [[Ant2-Proxy-Security-Manager]] v2.3. Uses three NGINX directives: `limit_conn`, `limit_req`, and `limit_rate`.

## The Three Directives

| Directive | Controls | Unit |
|-----------|---------|------|
| `limit_conn` | Max concurrent connections per IP | count |
| `limit_req` | Request rate per IP | `10r/s`, `60r/m` |
| `limit_rate` | Bandwidth per connection | `100k`, `1m` |
| `limit_rate_after` | Start throttling after N bytes | `500k` |

## NGINX Config Pattern (generated by Ant2)

```nginx
# In http{} block — zone defined per host
limit_req_zone $binary_remote_addr zone=req_1:10m rate=10r/s;
limit_conn_zone $binary_remote_addr zone=perip:10m;

# In server{} block
limit_conn perip 20;
limit_req zone=req_1 burst=30 nodelay;
limit_rate 1m;
limit_rate_after 500k;
```

Zones use unique names `req_{host_id}` to avoid conflicts between hosts.

## Database Schema (v2.3 additions)

6 new columns added to `hosts` table:

```sql
limit_conn        INTEGER  DEFAULT 0    -- 0 = unlimited
limit_req_rate    TEXT     DEFAULT ""   -- e.g. "10r/s"
limit_req_burst   INTEGER  DEFAULT 0
limit_req_nodelay INTEGER  DEFAULT 0    -- 1 = nodelay flag
limit_rate        TEXT     DEFAULT ""   -- e.g. "100k"
limit_rate_after  TEXT     DEFAULT ""   -- e.g. "500k"
```

## Monitor API

`GET /api/logs/rate-limit/stats?range=1h|6h|24h|7d`

Parses:
- NGINX error logs for `"limiting requests"` / `"limiting connections"` lines
- JSON access logs for HTTP 429 responses

## All Rate Limit Responses Use HTTP 429

Configured as `limit_req_status 429` and `limit_conn_status 429` — standard "Too Many Requests" status.

## Rate Format Normalization (v2.3.6 fix)

nginx `limit_req_zone` requires the `r` prefix in the rate value: `10r/s`, `60r/m`. Inputs like `10/s` or `100/m` cause nginx to fail config reload with a `Config Error` — silently producing a broken site.

[[Ant2-Proxy-Security-Manager]] v2.3.6 added a `normalizeRate()` function in `nginxConfig.js`:

```js
// "100/m" → "100r/m", "10r/s" → "10r/s" (idempotent)
function normalizeRate(rate) {
  return String(rate).trim().replace(/^(\d+)(\/[sm])$/, '$1r$2');
}
```

Applied in both `buildRateLimitZones` (nginx config generation) and the POST/PUT API route handlers in `hosts.js`.

## Custom 429 Error Page

Added in v2.3.6. Previously rate-limited requests returned nginx's bare default 429 page with the "nginx" server string visible. Now intercepted with a branded custom error page. See also [[server-header-disclosure]].
